ВОПРОС: как скрыть косметику;
0. Пример: ^(?!\\[PRISONEVO).*?(?=.*\\bкак\\b)(?=.*\\bскрыть\\b)(?=.*\\bкосметику\\b).* 

 Пояснение шаблона:
1. ^(?!\\[PRISONEVO)
Проверяет, что сообщение не начинается с "[PRISONEVO". Если начинается, выражение не срабатывает.

2. .*?
Разрешает любой текст перед ключевыми словами.

3. (?=.*\\bкак\\b)
Проверяет наличие слова "как" в тексте.

4. (?=.*\\bскрыть\\b)
Проверяет наличие слова "скрыть".

5. (?=.*\\bкосметику\\b)
Проверяет наличие слова "косметику".

6. .*
Разрешает любой текст после указанных слов.
